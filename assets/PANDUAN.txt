CAFE LADA HITAM — APLIKASI PEMESANAN

1. COBA TAMPILAN TANPA XAMPP
Buka index.html di browser. Ini mode DEMO: favorit, keranjang, dan pesanan
tersimpan di browser perangkat itu saja. Akun demo adalah profil lokal,
bukan autentikasi sungguhan; gunakan data contoh. Admin hanya ada di mode PHP.

2. MENJALANKAN VERSI PHP + MYSQL
- Gunakan XAMPP dengan PHP 8.0+ dan MySQL/MariaDB (PDO MySQL aktif).
- Salin folder lada-hitam ke C:\xampp\htdocs\
- Nyalakan Apache dan MySQL.
- Buka http://localhost/phpmyadmin
- Untuk pemasangan BARU, import database.sql. Database: ladahitam_cafe_v3.
- Buka config/database.php dan cocokkan host, nama database, user, password.
- Buka http://localhost/lada-hitam/index.php
- Pelanggan dapat mendaftar lalu masuk untuk membuat pesanan.
- Admin awal: username admin | password LadaHitam2026!
- Setelah login admin, klik Kelola cafe di sidebar. Pada HP, opsi Kelola cafe
  tersedia di dialog akun.
- Kelola pesanan: ubah Menunggu / Disiapkan / Selesai / Dibatalkan.
- Kelola menu: ubah harga dan ketersediaan. Harga checkout dihitung di server.
- Pembayaran dilakukan di kasir; tidak ada payment gateway/transfer otomatis.

3. JIKA DATABASE LAMA SUDAH BERISI DATA
Backup dulu database melalui Export di phpMyAdmin.
Jangan import database.sql ke database lama yang berisi pesanan.
Untuk revisi 2, buka website dahulu agar perbaikan otomatis berjalan.
upgrade-database.sql disediakan untuk migrasi manual dari versi awal saja. Menu dan pesanan lama dipertahankan. Jika admin lama sudah
ada, password lama tidak diganti. Password akun lama harus berupa hash bcrypt
atau password_hash PHP. Akun dengan hash MD5 perlu direset sebelum dipakai.

4. SEBELUM DIPAKAI ONLINE
Ganti password admin awal dari terminal XAMPP:
C:\xampp\php\php.exe C:\xampp\htdocs\lada-hitam\ubah-password-admin.php
Masukkan username admin dan password baru. Sesuaikan database hosting di
config/database.php. Server harus mendukung PHP + MySQL; GitHub Pages hanya
menjalankan index.html sebagai demo. Gunakan HTTPS di hosting.

5. GAMBAR DAN MENU
Semua 25 gambar menu kiriman sudah dimasukkan: 10 minuman, 10 makanan,
5 camilan/dessert. Gambar dioptimalkan ke WebP agar ZIP dan halaman lebih ringan.

ikan bakar dan dua gambar kentang goreng yang mirip. Harga merupakan CONTOH,
bukan harga resmi cafe. Koreksi sebelum dipakai untuk pelanggan.

Mode demo memakai assets/menu.js sehingga perubahannya terpisah dari database.
